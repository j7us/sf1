Пусть в метод будет передан не нулевой массив с более чем одним элементом.

Далее рассмотрим инварианты цикла:

для каждого i характерен инвариант:
res = max(arr[0]-arr[1])

Предположим, что i = 5
int current = arr[5];
если current > max, то max = arr[5];
