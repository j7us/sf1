Докажем для начала по отдельности первый функции abs и max

1) abs
    {P: n = a && a >= 0} abs(n) {Q: res = a}
    {P: n = a && a < 0} abs(n) {Q: res = -a}
    Доказательство:
    Пусть в предусловии значение n будет больше или равным 0

    В теле функции если значение n >= 0, то будет возвращено тоже значение

    Результат совпадает с постусловием.

    В случае если в предусловии значение n меньше 0

    В теле функции если значение n < 0, то будет возвращено -n

    Результат совпадает с постусловием


2) max
    {P: x = a && y = b && a >= b} max(x, y) {Q: res = a}
    Доказательство:
    Пусть в предусловии значение x и y такие, что x >= y

    В теле функции если значение x больше чем y, то будет возвращено значение x

    Результат совпадает с постусловием

Пусть соблюдается предусловие, что значение x по модулю больше или равно y

Следующим этапом будет идти выполнение функции max, предусловие выполняется, по предыдущему доказательству мы имеем,
