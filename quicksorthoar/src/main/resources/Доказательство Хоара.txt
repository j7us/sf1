{P: arr.length > 0} quickSort(arr) {Q: sort(arr)}

Доказательство:
Для каждого шага рекурсии результатом будет инвариант
R: pivot = arr[i] && pivot > {arr[i - 1], arr[i - 2], ...} && pivot < {arr[i + 1], arr[i + 2], ...}
    && arrLeft = {arr[0], arr[1], .. arr[pivot - 1]} && arrRight = {arr[pivot + 1], arr[pivot + 2], ...}

Рассмотрим шаг рекурсии, мы пройдем по подмассив и если значение ячейки меньше, чем выбранный нами pivot, то
элемент будет смещен на индекс i.
На следующие этапы рекурсии будут переданы подмассивы с индексами до i и после i.

Так будуд отсортированы все части текущего массива из-за чего массив целиком будет отсортирован.
